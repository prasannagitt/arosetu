# AroSetu — Sprint 1 Backlog

## Sprint Information

**Sprint:** Sprint 1

**Sprint Goal:**

Set up the AroSetu full-stack development foundation and implement
the initial authentication and authorization system.

**Sprint Duration:** 2 weeks

**Status:** Planned

---

# 1. Sprint Goal

By the end of Sprint 1, AroSetu should have:

- A properly structured Git repository.
- A working Spring Boot backend.
- A working React frontend.
- A PostgreSQL database.
- Backend-to-database connectivity.
- Basic REST API structure.
- User registration.
- User login.
- Password hashing.
- JWT-based authentication.
- Initial role-based authorization.
- Basic error handling and validation.
- A working development environment.

The application does not need to contain patient, doctor, appointment,
laboratory, prescription, or pharmacy workflows during this sprint.
